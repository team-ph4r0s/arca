# Arca 0.7.1 — Pharos

## Русский

Команда **Pharos** выпускает Arca 0.7.1 как небольшой стабилизационный релиз после 0.7.0.

В iOS просмотрщик теперь передаёт полный объект диагностики из X-Ray в экран документа. При переходе к просмотру сохраняются фактические значения расхода Wasm-топлива, лимита топлива, пиковой памяти и времени выполнения. В отчёте эти значения показываются явно, поэтому нулевые показатели больше не появляются из-за навигации между экранами.

Разбор элементов безопасного просмотра стал строгим. Для каждого элемента проверяются тип, обязательные поля, числовые массивы, таблицы, строки и дополнительные атрибуты rich text. Неизвестный тип или повреждённое поле возвращают диагностируемую ошибку вместо тихого удаления через `compactMap`. Поддержаны поля `fg`, `bg` и `scale` из JSON ядра, а SwiftUI применяет цвет текста, фон, масштаб, верхний и нижний индекс.

Добавлены регрессионные проверки реального формата JSON, включая rich-run данные и неизвестные типы. Обновлены версии всех workspace crates, Android manifest, iOS project metadata, README, архитектурное руководство, модель угроз и платформенные документы.

Версия приложения: `0.7.1`. Android `versionCode`: `7001`.

Проверки, требующие локального Docker daemon и Xcode, должны выполняться в CI или на машине с контейнером `arca-dev`; исходный checkout не содержит локального Rust/Swift toolchain.

## English

The **Pharos** team is releasing Arca 0.7.1 as a focused stabilization release after 0.7.0.

The iOS viewer now carries the complete X-Ray diagnostics object into the document screen. Navigation preserves the real Wasm fuel usage, fuel limit, peak memory and wall time, and the report displays those values explicitly. Zero telemetry caused by replacing the scan diagnostics during navigation is removed.

Safe-preview decoding is now strict. Each item validates its kind, required fields, numeric arrays, tables, runs and rich-text attributes. Unknown kinds and malformed fields return a diagnosable error instead of being silently removed by `compactMap`. The JSON fields `fg`, `bg` and `scale` are accepted from the engine, and SwiftUI applies text colour, background, scale, superscript and subscript formatting.

Regression coverage now includes the engine’s rich-run JSON shape and unknown item rejection. Workspace crate versions, the Android manifest, iOS project metadata, README, architecture guide, threat model and platform documents were updated together.

Application version: `0.7.1`. Android `versionCode`: `7001`.

Checks that require a local Docker daemon and Xcode must run in CI or on a machine with the `arca-dev` container; this checkout has no local Rust or Swift toolchain.
