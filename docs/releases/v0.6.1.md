# Arca 0.6.1 — исправление просмотра документов на iOS (пре-релиз)

* Исправлена передача открытого документа в безопасный просмотрщик iOS: содержимое запрашивается для активной сессии.
* Ошибки выбора файла и загрузки содержимого теперь отображаются пользователю; переключение разделов не смешивает результаты разных запросов.
* Android выпускается с новой версией; изменений его функциональности в этом выпуске нет.
* Неподписанный IPA предназначен для тестирования и требует собственной подписи для установки на устройство. Сборка и тесты iOS выполняются в CI; ручная проверка на iPhone для этой версии ещё не проведена.

# Arca 0.6.1 — iOS document preview fix (pre-release)

* The iOS safe viewer requests content using the open document session.
* File selection and preview loading errors are surfaced, and changing sections does not mix results from different requests.
* Android is released with the updated version; its functionality is unchanged.
* The unsigned IPA is for testing and must be signed to install on a device. iOS builds and tests run in CI; this version has not yet been manually tested on an iPhone.
