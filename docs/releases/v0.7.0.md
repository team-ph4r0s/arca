# Arca 0.7.0 — Pharos

## Русский

Команда **Pharos** выпускает Arca 0.7.0 как обновление безопасного просмотра документов для Android и iOS.

В этом выпуске мы восстановили передачу диагностик песочницы в iOS при переходе из «Рентгена» в просмотр. Экран сохраняет фактические значения топлива Wasm, лимита топлива, пиковой памяти и времени выполнения. В нижней строке отчёта теперь видны топливо, память и время последнего запуска.

Конвейер JSON просмотра стал строгим и диагностируемым. Элементы с неизвестным типом, неверными полями или повреждёнными массивами больше не исчезают через `compactMap`: приложение возвращает точную ошибку декодирования. Парсер iOS также принимает цвет текста, цвет фона и масштаб шрифта, которые выдаёт `arca-engine`, а просмотр применяет эти значения вместе с верхним и нижним индексом.

Статический анализ макросов остаётся полностью безопасным: исходный текст, процедуры, IOC и поведенческие шаги отображаются как текст внутри изолированной Wasm-песочницы и не исполняются. Android и iOS используют единый контракт отчёта.

Версия приложения: `0.7.0`. Android `versionCode`: `7000`.

## English

The **Pharos** team is releasing Arca 0.7.0 as a safer document viewer update for Android and iOS.

This release restores sandbox diagnostics when iOS moves from the X-Ray report into the viewer. The screen keeps the real Wasm fuel usage, fuel limit, peak memory and wall time from the scan. The report footer now shows fuel, memory and elapsed time for the last run.

Preview JSON decoding is strict and observable. Unknown item kinds, invalid fields and malformed arrays no longer disappear through `compactMap`; the app reports the exact decoding failure. The iOS parser also accepts text colour, background colour and font scale emitted by `arca-engine`, and the viewer applies those values together with superscript and subscript formatting.

Macro inspection remains static and safe: source text, procedures, IOCs and behaviour steps are displayed as text inside the isolated Wasm sandbox and are never executed. Android and iOS consume the same report contract.

Application version: `0.7.0`. Android `versionCode`: `7000`.
